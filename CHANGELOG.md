# Changelog

## 2.0.1

- Fixed the Blacksteele drawing: the raised fore turret now stands on its barbette instead of hanging in the air, in the sonar display and in the progress bar.

## 2.0.0

The plugin is now called **Warden & Colonial Navy** and covers both factions.

- Two new themes: **Colonial Navy Conqueror** (destroyer) and **Colonial Navy Trident** (submarine), each with its own editor colour scheme, sea chart, sonar display and progress bar vessel.
- All four vessels were redrawn with the ships in the game as reference.
- The Colonial sonar displays have wedge marks around the rim.

**Upgrading from 1.0.0:** the plugin has a new id, so the IDE treats it as a different plugin. Uninstall *Warden Navy* before installing this version, then pick your theme and set the switches again.

## 1.0.0

First public release.

- Two dark themes, **Warden Navy Blacksteele** and **Warden Navy Nakki**, each with its own editor colour scheme.
- Sea chart background with a sonar display and a warship or submarine.
- 45 nautical icons: sea mines for breakpoints, crates for folders, and tool window, run and status icons.
- Progress bar with a ship or submarine on the waterline.
- Effects: air bubbles when typing pauses, a torpedo on *Delete Line*, a sonar ping when a build or run finishes.
- Notifications styled as radio telegram slips.
- Depth gauge in the status bar.
- Settings page to switch the progress bar and each effect on or off.
